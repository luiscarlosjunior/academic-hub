Tópico 2 · Vetores

Um vetor (array) é uma sequência de elementos do mesmo tipo guardados em posições contíguas da memória. É a estrutura mais simples e a base de quase todas as outras: filas, pilhas, tabelas hash e matrizes são construídas sobre vetores. Entender o custo de cada operação aqui explica o custo de todo o restante.

Objetivos desta página. Ao final, você deve conseguir:

  • explicar por que o acesso por índice é O(1) e a busca por valor é O(n);
  • implementar, em C, acesso, busca, inserção e remoção com verificação de limites;
  • usar realocação para criar um vetor dinâmico com inserção amortizada O(1) no fim;
  • resolver problemas com os padrões de manipulação in-place: inversão, rotação e compactação.

Teoria: o que acontece na memória

Se o primeiro elemento de um vetor de inteiros está no endereço base e cada inteiro ocupa s bytes, o elemento i está no endereço base + i · s. Não há busca: uma multiplicação e uma soma dão o endereço. Em C isso é literal, porque a[i] é definido como *(a + i) (KERNIGHAN; RITCHIE, 1988, cap. 5).

Essa contiguidade traz duas consequências práticas. A primeira é a localidade: percorrer o vetor em ordem carrega blocos inteiros para o cache do processador, o que costuma tornar o percurso muito mais rápido do que a análise sugere (HENNESSY; PATTERSON, 2017, cap. 2). A segunda é a rigidez: inserir ou remover no meio exige deslocar os elementos seguintes, e o tamanho fixo obriga a realocar quando a capacidade acaba.

C não verifica limites. Acessar a[10] num vetor de seis posições é comportamento indefinido: o programa pode travar, devolver lixo ou corromper outra variável, sem aviso (ISO/IEC, 2018). Por isso, os exemplos desta página sempre checam os índices antes de acessar.

Operação 1 · Acesso por índice e busca por valor

O acesso recebe um índice e devolve o valor: O(1), sem depender de n. A busca recebe um valor e precisa descobrir onde ele está: sem ordem, o pior caso é percorrer tudo, O(n). Na animação, a primeira parte mostra o acesso direto e a segunda, a busca comparando um elemento de cada vez.

Em C · 02-vetores.c · op:acessar

static int vetor_acessar(const Vetor *v, size_t i, int *saida) {
    if (i >= v->tam) return 0;      /* C não verifica limites: a checagem é nossa */
    *saida = v->dados[i];
    return 1;
}

Em C · 02-vetores.c · op:buscar

static long vetor_buscar(const Vetor *v, int x) {
    for (size_t i = 0; i < v->tam; i++)
        if (v->dados[i] == x) return (long)i;
    return -1;
}

Animação: acesso e busca linear

Operação 2 · Crescer e inserir no fim

Um vetor de capacidade fixa não cresce. A solução é o vetor dinâmico: quando a capacidade acaba, pedimos um bloco com o dobro do tamanho, copiamos tudo e liberamos o antigo. A chamada que realoca custa O(n), mas ela é rara. Como o tamanho dobra, a soma das cópias ao longo de n inserções é menor que 2n, e o custo amortizado por inserção é O(1). Esse é o mesmo princípio do ArrayList de Java e do std::vector de C++.

Em C · 02-vetores.c · op:crescer

static int vetor_crescer(Vetor *v) {
    size_t nova = (v->cap == 0) ? 4 : v->cap * 2;
    int *p = realloc(v->dados, nova * sizeof *p);
    if (p == NULL) return 0;
    v->dados = p;
    v->cap = nova;
    return 1;
}

Em C · 02-vetores.c · op:inserir-fim

static int vetor_push(Vetor *v, int x) {
    if (v->tam == v->cap && !vetor_crescer(v)) return 0;
    v->dados[v->tam++] = x;
    return 1;
}

Animação: o vetor cresce por duplicação

Operação 3 · Inserir e remover no meio

Para abrir espaço na posição p, todos os elementos de p até o fim precisam andar uma casa para a direita. memmove faz essa cópia com segurança mesmo quando as regiões se sobrepõem. Remover é o inverso: os elementos andam para a esquerda, sem deixar buraco. Ambas custam O(n) no pior caso (inserir ou remover no início), e O(1) no fim.

Em C · 02-vetores.c · op:inserir-posicao

static int vetor_inserir(Vetor *v, size_t pos, int x) {
    if (pos > v->tam) return 0;
    if (v->tam == v->cap && !vetor_crescer(v)) return 0;
    memmove(&v->dados[pos + 1], &v->dados[pos], (v->tam - pos) * sizeof *v->dados);
    v->dados[pos] = x;
    v->tam++;
    return 1;
}

Em C · 02-vetores.c · op:remover-posicao

static int vetor_remover(Vetor *v, size_t pos, int *removido) {
    if (pos >= v->tam) return 0;
    *removido = v->dados[pos];
    memmove(&v->dados[pos], &v->dados[pos + 1], (v->tam - pos - 1) * sizeof *v->dados);
    v->tam--;
    return 1;
}

Padrões de resolução com vetores

Dois ponteiros

Dois índices avançam pelo vetor (um de cada lado, ou um lendo e outro escrevendo). Usado em inversão, compactação e pares com soma fixa. Página 11.

Trabalhar in place

Reorganizar o próprio vetor, sem alocar outro. Espaço O(1). Exige cuidado com a ordem das escritas.

Reverter em blocos

Inverter partes do vetor e depois o todo produz rotações sem memória extra (exercício 2).

Janela ou soma acumulada

Em vez de recalcular somas, atualizar a soma ao entrar e sair um elemento (exercício 4 e página 11).

Exercícios resolvidos

Exercício 1: inverter um vetor sem memória extra

Enunciado. Inverta um vetor de n inteiros usando O(1) de espaço auxiliar.

Padrão: dois ponteiros nas extremidades. i começa no início e j no fim; trocamos e avançamos os dois até se cruzarem.

Complexidade: O(n) de tempo, O(1) de espaço. Cada elemento é tocado uma vez.

Em C · 02-vetores.c · ex:inverter

static void inverter(int a[], size_t n) {
    if (n < 2) return;
    size_t i = 0, j = n - 1;
    while (i < j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
        i++;
        j--;
    }
}

Exercício 2: rotacionar à esquerda por k posições

Enunciado. Rotacione o vetor [1,2,3,4,5,6,7] em 2 posições à esquerda, sem memória extra.

Ideia. Rotacionar à esquerda por k equivale a: inverter a parte [0, k), inverter [k, n), e depois inverter o vetor inteiro. Exemplo: [1,2 | 3..7] vira [2,1 | 7..3], e a inversão final dá [3..7 | 1,2].

Cuidado: use k %= n antes, para tratar k maior que n.

Complexidade: O(n) de tempo, O(1) de espaço.

Em C · 02-vetores.c · ex:rotacionar

static void inverter_faixa(int a[], size_t ini, size_t fim) {   /* fim exclusivo */
    if (fim - ini < 2) return;
    size_t i = ini, j = fim - 1;
    while (i < j) {
        int t = a[i];
        a[i] = a[j];
        a[j] = t;
        i++;
        j--;
    }
}

static void rotacionar_esq(int a[], size_t n, size_t k) {
    if (n == 0) return;
    k %= n;
    inverter_faixa(a, 0, k);
    inverter_faixa(a, k, n);
    inverter_faixa(a, 0, n);
}

Exercício 3: remover duplicados de um vetor ordenado

Enunciado. Em um vetor ordenado, remova as repetições e devolva o novo tamanho, sem alocar outro vetor.

Padrão: leitor e escritor. r lê todas as posições; w marca onde o próximo valor distinto deve ser gravado. Como o vetor é ordenado, os repetidos são vizinhos, e basta comparar com o último valor gravado.

Complexidade: O(n) de tempo, O(1) de espaço.

Em C · 02-vetores.c · ex:duplicados

static size_t remover_duplicados(int a[], size_t n) {
    if (n == 0) return 0;
    size_t w = 1;                       /* próxima posição de escrita */
    for (size_t r = 1; r < n; r++)
        if (a[r] != a[w - 1]) a[w++] = a[r];
    return w;
}

Exercício 4: maior soma de subvetor contíguo (Kadane)

Enunciado. Dado um vetor com valores negativos e positivos, encontre a maior soma de um trecho contínuo.

Ideia. Para cada posição, decida: vale a pena continuar o trecho anterior, ou começar um novo a partir daqui? Se a soma acumulada até agora é positiva, ela ajuda o próximo elemento; se é negativa, só atrapalha, e recomeçamos. Guardamos o melhor valor visto. Esse é um exemplo de programação dinâmica com um único estado (página 11).

Complexidade: O(n) de tempo, O(1) de espaço.

Em C · 02-vetores.c · ex:kadane

static int maior_soma(const int a[], size_t n) {
    int melhor = a[0], atual = a[0];
    for (size_t i = 1; i < n; i++) {
        atual = (atual > 0) ? atual + a[i] : a[i];
        if (atual > melhor) melhor = atual;
    }
    return melhor;
}

Exercícios propostos

P1. Mova todos os zeros de um vetor para o fim, mantendo a ordem dos demais, em O(n) e O(1) de espaço.

Resposta: use um escritor w que avança apenas ao gravar um valor não nulo; no fim, preencha de w até o fim com zeros. É a mesma ideia de remover duplicados, trocando o critério.

P2. Junte dois vetores ordenados em um só, em ordem, em O(n + m).

Resposta: dois ponteiros, um em cada vetor. Em cada passo, copie o menor dos dois valores atuais. Esse é o passo de intercalação do merge sort (página 4).

Teste seus conhecimentos

Por que a inserção no fim de um vetor dinâmico é O(1) amortizado, apesar de algumas chamadas custarem O(n)?

Correto. A soma das cópias em n inserções é menor que 2n. Dividindo pelo número de inserções, o custo médio por operação é constante.

Qual o custo de remover o primeiro elemento de um vetor com n elementos?

Correto. Todos os n − 1 elementos restantes precisam andar uma posição para a esquerda.

Por que um programa em C deve checar o índice antes de acessar a[i]?

Correto. O compilador não impede o acesso fora do bloco. O programa pode falhar ou corromper outra variável sem nenhum aviso.

O que levar desta página

  • Acesso por índice é O(1); busca por valor sem ordem é O(n).
  • Inserir ou remover no meio custa O(n), porque os elementos precisam se deslocar.
  • Vetor dinâmico dobra a capacidade: inserção no fim é O(1) amortizado, e a realocação custa O(n) de espaço temporário.
  • Em C, a checagem de índices é responsabilidade do programador.
  • Os padrões de dois ponteiros e de trabalho in place aparecem em quase todos os exercícios de vetor.
