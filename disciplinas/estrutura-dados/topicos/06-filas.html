Tópico 6 · Filas

Uma fila impõe uma ordem de atendimento: quem chega primeiro é atendido primeiro (FIFO, first in, first out). É o modelo de filas de banco, de impressão, de mensagens entre serviços e de buffers de rede e áudio. Na computação, é também a estrutura por trás da busca em largura, que veremos na página de grafos.

Objetivos desta página. Ao final, você deve conseguir:

  • implementar fila com operações em O(1): enqueue, dequeue, frente e vazia;
  • explicar por que um vetor comum não serve bem para a fila e como o buffer circular resolve isso;
  • escolher entre buffer circular (capacidade fixa) e fila encadeada (crescimento livre);
  • modelar simulações com fila e resolver problemas que usam fila como ferramenta.

Teoria: por que não usar um vetor comum

Um vetor comum tem enqueue barato (escreve no fim), mas dequeue caro: remover o primeiro elemento exige deslocar todos os outros, O(n). Uma fila que processa milhões de itens ficaria quadrática. Há duas saídas clássicas, ambas com todas as operações em O(1):

  • Buffer circular: um vetor de capacidade fixa, em que o início e o fim "dão a volta" pela aritmética módulo a capacidade. Não há deslocamento.
  • Fila encadeada: nós alocados um a um, com ponteiros para o início e para o fim. Cresce sem limite, ao custo de uma alocação por elemento.

Em sistemas com memória limitada e tamanho previsível (um buffer de áudio, por exemplo), o buffer circular é o padrão. Quando o volume é imprevisível, a fila encadeada evita o problema de realocar.

Operação 1 · Buffer circular: enqueue e dequeue

A fila guarda a posição da frente e a quantidade de elementos. O fim é calculado: (frente + tam) % CAP. enqueue grava nessa posição e incrementa tam. dequeue lê a frente, avança a frente módulo CAP e decrementa tam. A fila está cheia quando tam == CAP. As posições liberadas no início são reaproveitadas pelo fim, que dá a volta: a lotação depende só do número de elementos, não de onde eles estão.

Em C · 06-filas.c · op:enqueue

typedef struct {
    int dados[CAP];
    size_t frente;      /* índice do primeiro elemento */
    size_t tam;         /* quantos elementos estão na fila */
} FilaCirc;

static int fila_enqueue(FilaCirc *f, int x) {
    if (f->tam == CAP) return 0;                    /* cheia */
    f->dados[(f->frente + f->tam) % CAP] = x;       /* índice circular */
    f->tam++;
    return 1;
}

Em C · 06-filas.c · op:dequeue

static int fila_dequeue(FilaCirc *f, int *saida) {
    if (f->tam == 0) return 0;                      /* vazia */
    *saida = f->dados[f->frente];
    f->frente = (f->frente + 1) % CAP;
    f->tam--;
    return 1;
}

Em C · 06-filas.c · op:peek

static int fila_frente(const FilaCirc *f, int *saida) {
    if (f->tam == 0) return 0;
    *saida = f->dados[f->frente];
    return 1;
}

Operação 2 · Fila encadeada

A fila encadeada mantém dois ponteiros: ini aponta para o primeiro nó, fim para o último. Inserir no fim liga o novo nó ao último; remover do início desliga o primeiro. O caso especial é a fila vazia, em que os dois ponteiros são nulos e precisam ser ajustados juntos. É o caso mais fácil de errar: esquecer de zerar fim ao remover o último nó.

Em C · 06-filas.c · op:fila-encadeada

typedef struct No {
    int v;
    struct No *prox;
} No;

typedef struct {
    No *ini, *fim;
} FilaLig;

static int lig_enqueue(FilaLig *f, int v) {
    No *n = malloc(sizeof *n);
    if (n == NULL) return 0;
    n->v = v;
    n->prox = NULL;
    if (f->fim) f->fim->prox = n;
    else f->ini = n;
    f->fim = n;
    return 1;
}

static int lig_dequeue(FilaLig *f, int *saida) {
    No *n = f->ini;
    if (n == NULL) return 0;
    *saida = n->v;
    f->ini = n->prox;
    if (f->ini == NULL) f->fim = NULL;
    free(n);
    return 1;
}

static void lig_liberar(FilaLig *f) {
    int descartado;
    while (lig_dequeue(f, &descartado)) { }
}

Padrões de resolução com filas

Processar em camadas

Quando a ordem é “primeiro o que está mais perto”, use fila: é a base da BFS, que calcula distâncias em grafos sem peso e em grades.

Simulação de turnos

Processos, clientes ou tarefas que voltam ao fim da fila após um turno, como no round-robin (exercício 1).

Duas pilhas

Pilhas invertem a ordem. Duas pilhas em sequência devolvem a ordem original: é a fila com custo amortizado O(1) (exercício 2).

Deque para janelas

Uma fila de duas pontas (deque) mantém o máximo de uma janela deslizante em O(n). Fila e janela se encontram na página 11.

Exercícios resolvidos

Exercício 1: escalonamento round-robin

Enunciado. Processos com durações conhecidas usam a CPU em fatias de tamanho fixo (quantum). Um processo que não terminou volta ao fim da fila. Simule e diga quando cada um termina.

Padrão: simulação por fila. Cada processo é retirado da frente, recebe uma fatia, e se ainda falta tempo, volta ao fim. Assim, a ordem de atendimento é justa: nenhum processo espera mais que uma volta completa da fila.

Para durações {5, 3, 8} e quantum 2: o processo 1 termina em t = 9, o 0 em t = 12, o 2 em t = 16.

Complexidade: o número de fatias é ⌈soma das durações / quantum⌉, e cada fatia custa O(1). Total O(T / q), com T a soma das durações.

Em C · 06-filas.c · ex:round-robin

static void round_robin(const int duracao[], size_t n, int quantum) {
    int restante[16];
    FilaLig f = {NULL, NULL};
    for (size_t i = 0; i < n && i < 16; i++) {
        restante[i] = duracao[i];
        lig_enqueue(&f, (int)i);
    }
    int t = 0, idx;
    while (lig_dequeue(&f, &idx)) {
        int fatia = restante[idx] < quantum ? restante[idx] : quantum;
        t += fatia;
        restante[idx] -= fatia;
        if (restante[idx] > 0) lig_enqueue(&f, idx);      /* volta para o fim da fila */
        else printf("  processo %d termina em t=%d\n", idx, t);
    }
}

Exercício 2: fila com duas pilhas

Enunciado. Implemente uma fila usando apenas duas pilhas. Qual o custo de cada operação?

Ideia. enqueue empilha na pilha de entrada. dequeue olha a pilha de saída: se ela está vazia, passa todos os elementos da entrada para a saída, o que inverte a ordem e coloca o mais antigo no topo. Se a saída não está vazia, basta desempilhar dela.

Análise amortizada: um elemento é movido da entrada para a saída no máximo uma vez. Em n operações, há no máximo n movimentos. O custo amortizado por operação é O(1), embora uma única dequeue possa custar O(n).

Em C · 06-filas.c · ex:duas-pilhas

typedef struct {
    int d[32];
    int n;
} Pilha;

static void p_push(Pilha *p, int x) { p->d[p->n++] = x; }

static int p_pop(Pilha *p, int *x) {
    if (p->n == 0) return 0;
    *x = p->d[--p->n];
    return 1;
}

typedef struct {
    Pilha entrada, saida;
} FilaDuasPilhas;

static void fdp_enqueue(FilaDuasPilhas *q, int x) {
    p_push(&q->entrada, x);
}

/* Amortizado O(1): cada elemento é movido da entrada para a saída no máximo uma vez */
static int fdp_dequeue(FilaDuasPilhas *q, int *x) {
    if (q->saida.n == 0) {
        int t;
        while (p_pop(&q->entrada, &t)) p_push(&q->saida, t);
    }
    return p_pop(&q->saida, x);
}

Exercícios propostos

P1. Por que, num buffer circular, não basta comparar frente == fim para distinguir fila vazia de fila cheia? Proponha duas soluções.

Resposta: ambos os estados fazem frente e fim coincidirem. Solução 1: manter um contador tam, como nesta página. Solução 2: deixar uma posição sempre vazia, e considerar cheia quando (fim + 1) % CAP == frente; isso gasta uma posição, mas dispensa o contador.

P2. Explique por que a fila encadeada é mais lenta que o buffer circular na prática, embora ambas sejam O(1).

Resposta: cada enqueue faz uma alocação (malloc), e os nós ficam espalhados na memória. O buffer circular grava em um bloco contíguo, o que aproveita o cache. A complexidade assintótica é a mesma; a constante, não.

Teste seus conhecimentos

Qual é a ordem de saída de uma fila após enqueue(1), enqueue(2), dequeue(), enqueue(3), dequeue()?

Correto. Saem 1 (o primeiro), depois 2 (o próximo mais antigo). O 3 ainda está na fila.

Por que um buffer circular não precisa deslocar elementos ao remover?

Correto. A remoção só move o índice da frente. O resto do vetor fica onde está.

Qual o custo amortizado de dequeue em uma fila de duas pilhas?

Correto. Cada elemento é transferido uma só vez, então o custo total de n operações é O(n), ou seja, O(1) por operação em média.

O que levar desta página

  • Fila é FIFO. Todas as operações devem ser O(1): use buffer circular ou fila encadeada.
  • Num vetor simples, dequeue é O(n) por causa do deslocamento. Isso é o que o buffer circular evita.
  • Fila modela turnos, camadas e simulações.
  • Análise amortizada explica por que duas pilhas dão uma fila barata na média.
