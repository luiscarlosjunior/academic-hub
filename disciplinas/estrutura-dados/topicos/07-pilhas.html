Tópico 7 · Pilhas

Uma pilha impõe a ordem inversa: o último a entrar é o primeiro a sair (LIFO, last in, first out). Só o topo é acessível. Parece restritivo, mas essa restrição é justamente o que torna a pilha poderosa: tudo que depende de "voltar ao que estava antes" é uma pilha. A pilha de chamadas de funções, o desfazer de editores, o casamento de parênteses e a avaliação de expressões são exemplos.

Objetivos desta página. Ao final, você deve conseguir:

  • implementar push, pop e peek em C com verificação de limites, todos em O(1);
  • usar uma pilha para validar parênteses e para avaliar expressões pós-fixas;
  • converter uma expressão infixa em pós-fixa com o algoritmo shunting-yard;
  • resolver problemas com pilha monotônica e pilha auxiliar.

Teoria: onde a pilha está escondida

Quando uma função chama outra, o processador guarda o endereço de retorno e as variáveis locais numa região de memória chamada pilha de execução. Ao retornar, essa região é desempilhada. É por isso que a recursão usa memória proporcional à sua profundidade, como vimos na página 1. Uma pilha explícita, feita por você, faz exatamente o mesmo trabalho, e é a forma de converter uma recursão profunda em iteração sem estourar a pilha do sistema.

A pilha é um tipo abstrato com um contrato: push(x) coloca x no topo; pop() remove e devolve o topo; peek() devolve o topo sem remover; vazia() diz se há elementos. Em um vetor com ponteiro para o topo, as quatro operações são O(1), sem deslocamento.

Operações básicas em C

A implementação usa um vetor fixo e o índice do topo, que vale −1 quando a pilha está vazia. Nesse caso, push precisa checar se há espaço e pop precisa checar se há elemento: esquecer qualquer uma das duas checagens é a causa mais comum de erros com pilhas em C.

static int push(Pilha *p, int x) {
    if (p->topo + 1 == MAX) return 0;             /* cheia */
    p->d[++p->topo] = x;
    return 1;
}

Em C · 07-pilhas.c · op:pop

static int pop(Pilha *p, int *x) {
    if (p->topo < 0) return 0;                    /* vazia */
    *x = p->d[p->topo--];
    return 1;
}

static int peek(const Pilha *p, int *x) {
    if (p->topo < 0) return 0;
    *x = p->d[p->topo];
    return 1;
}

Aplicação 1 · Validar parênteses

Cada abertura é empilhada. Cada fechamento precisa casar com o topo: se a pilha está vazia, há um fechamento sobrando; se o topo é do tipo errado, os pares se cruzam. Ao fim, a pilha deve estar vazia. Um contador de abertura não basta, porque {(}) tem o mesmo número de abre e fecha e ainda assim é inválido: a ordem importa, e a pilha guarda essa ordem.

Em C · 07-pilhas.c · op:parenteses

static int balanceada(const char *s) {
    Pilha p;
    pilha_iniciar(&p);
    for (; *s; s++) {
        int c = *s, t;
        if (c == '(' || c == '[' || c == '{') {
            push(&p, c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (!pop(&p, &t)) return 0;
            if ((c == ')' && t != '(') || (c == ']' && t != '[') || (c == '}' && t != '{'))
                return 0;
        }
    }
    return p.topo < 0;
}

Aplicação 2 · Avaliar expressões pós-fixas (RPN)

Na notação pós-fixa (reverse polish notation), o operador vem depois dos operandos: 3 4 + 2 * significa (3 + 4) * 2. Não há parênteses nem precedência, porque a ordem dos tokens já define a conta. Calculadoras e a linguagem Forth usam essa notação, e máquinas de pilha, como a JVM, usam a mesma ideia de operandos empilhados. A avaliação é simples: número faz push; operador faz pop de dois valores, calcula e empilha o resultado. Ao fim, deve sobrar exatamente um valor.

Em C · 07-pilhas.c · op:rpn

static int avaliar_rpn(const char *expr, int *resultado) {
    Pilha p;
    pilha_iniciar(&p);
    const char *s = expr;
    while (*s) {
        if (isspace((unsigned char)*s)) {
            s++;
        } else if (isdigit((unsigned char)*s)) {
            int v = 0;
            while (isdigit((unsigned char)*s)) v = v * 10 + (*s++ - '0');
            push(&p, v);
        } else {
            int b, a, r;
            if (!pop(&p, &b) || !pop(&p, &a)) return 0;   /* faltam operandos */
            switch (*s) {
                case '+': r = a + b; break;
                case '-': r = a - b; break;
                case '*': r = a * b; break;
                case '/': if (b == 0) return 0; r = a / b; break;
                default: return 0;
            }
            push(&p, r);
            s++;
        }
    }
    if (p.topo != 0) return 0;                   /* deve sobrar exatamente um valor */
    *resultado = p.d[0];
    return 1;
}

Aplicação 3 · Da notação infixa à pós-fixa

O algoritmo shunting-yard, de Dijkstra, converte a expressão que escrevemos (infixa) na pós-fixa, que a máquina avalia. A ideia: números vão direto para a saída; operadores esperam numa pilha até que um operador de precedência menor ou igual chegue (aí saem primeiro); parênteses marcam o limite. Cada token entra e sai da pilha no máximo uma vez, então o custo é O(n).

Em C · 07-pilhas.c · op:shunting-yard

static int precedencia(int op) {
    if (op == '+' || op == '-') return 1;
    if (op == '*' || op == '/') return 2;
    return 0;
}

static void infixa_para_posfixa(const char *in, char *out) {
    Pilha ops;
    pilha_iniciar(&ops);
    size_t k = 0;
    for (const char *s = in; *s; s++) {
        int t;
        if (isdigit((unsigned char)*s)) {
            out[k++] = *s;
        } else if (*s == '(') {
            push(&ops, '(');
        } else if (*s == ')') {
            while (peek(&ops, &t) && t != '(') {
                pop(&ops, &t);
                out[k++] = (char)t;
            }
            pop(&ops, &t);                       /* descarta '(' */
        } else {
            while (peek(&ops, &t) && t != '(' && precedencia(t) >= precedencia(*s)) {
                pop(&ops, &t);
                out[k++] = (char)t;
            }
            push(&ops, *s);
        }
    }
    int t;
    while (pop(&ops, &t)) out[k++] = (char)t;
    out[k] = '\0';
}

 * Pilhas em C: push, pop, peek; parênteses; avaliação pós-fixa (RPN);
 * conversão infixa→pós-fixa; e exercícios resolvidos.
 * Compilar: cc -std=c11 -Wall -Wextra -pedantic 07-pilhas.c -o pilhas
 */
#include <ctype.h>
#include <stdio.h>
#include <string.h>

#define MAX 64

typedef struct {
    int d[MAX];
    int topo;                   /* índice do topo; -1 = vazia */
} Pilha;

static int push(Pilha *p, int x) {
    if (p->topo + 1 == MAX) return 0;             /* cheia */
    p->d[++p->topo] = x;
    return 1;
}

static int pop(Pilha *p, int *x) {
    if (p->topo < 0) return 0;                    /* vazia */
    *x = p->d[p->topo--];
    return 1;
}

static int peek(const Pilha *p, int *x) {
    if (p->topo < 0) return 0;
    *x = p->d[p->topo];
    return 1;
}

static void pilha_iniciar(Pilha *p) { p->topo = -1; }

static int balanceada(const char *s) {
    Pilha p;
    pilha_iniciar(&p);
    for (; *s; s++) {
        int c = *s, t;
        if (c == '(' || c == '[' || c == '{') {
            push(&p, c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (!pop(&p, &t)) return 0;
            if ((c == ')' && t != '(') || (c == ']' && t != '[') || (c == '}' && t != '{'))
                return 0;
        }
    }
    return p.topo < 0;
}

typedef struct {
    Pilha dados;
    Pilha minimos;              /* guarda o mínimo de cada estado da pilha */
} PilhaMin;

static void pm_push(PilhaMin *p, int x) {
    push(&p->dados, x);
    int m;
    if (p->minimos.topo < 0 || (peek(&p->minimos, &m), x <= m)) push(&p->minimos, x);
}

static int pm_pop(PilhaMin *p, int *x) {
    if (!pop(&p->dados, x)) return 0;
    int m;
    peek(&p->minimos, &m);
    if (*x == m) pop(&p->minimos, &m);
    return 1;
}

static int pm_minimo(const PilhaMin *p, int *m) {
    return peek(&p->minimos, m);                 /* O(1) */
}

static void proximo_maior(const int a[], int res[], size_t n) {
    Pilha p;
    pilha_iniciar(&p);                           /* guarda índices, valores decrescentes */
    for (size_t i = 0; i < n; i++) res[i] = -1;
    for (size_t i = 0; i < n; i++) {
        int j = 0;
        while (peek(&p, &j) && a[j] < a[i]) {
            pop(&p, &j);
            res[j] = a[i];
        }
        push(&p, (int)i);
    }
}

static size_t remover_adjacentes(const char *s, char *out) {
    Pilha p;
    pilha_iniciar(&p);
    for (const char *c = s; *c; c++) {
        int t;
        if (peek(&p, &t) && t == *c) pop(&p, &t);
        else push(&p, *c);
    }
    size_t n = 0;
    for (int i = 0; i <= p.topo; i++) out[n++] = (char)p.d[i];
    out[n] = '\0';
    return n;
}

Padrões de resolução com pilhas

Casamento

Quando cada fechamento deve corresponder a uma abertura anterior (parênteses, tags HTML, blocos), empilhe as aberturas.

Pilha auxiliar

Guarde junto com cada estado informação extra, como o mínimo até ali, para responder em O(1) (exercício 1).

Pilha monotônica

Mantenha a pilha em ordem crescente ou decrescente. Quando um novo elemento quebra a ordem, os elementos removidos ganham uma resposta (exercício 2).

Cancelamento

Quando um item cancela o anterior (como dois caracteres iguais seguidos), basta olhar o topo (exercício 3).

Exercícios resolvidos

Exercício 1: pilha com mínimo em O(1)

Enunciado. Projete uma pilha que, além de push, pop, devolva o menor valor presente em O(1).

Ideia. Mantenha uma segunda pilha com os mínimos. Ao empilhar x, se x é menor ou igual ao mínimo atual, empilhe-o também nos mínimos. Ao desempilhar, se o valor removido é igual ao topo dos mínimos, remova dos dois. Assim, o topo dos mínimos é sempre o mínimo da pilha inteira, mesmo depois de removidos elementos.

Complexidade: O(1) em todas as operações; espaço O(n).

}

Exercício 2: próximo maior elemento

Enunciado. Para cada posição, encontre o primeiro valor à direita que é maior que ele, ou −1.

Padrão: pilha monotônica decrescente de índices. Ao processar a[i], todo índice da pilha cujo valor é menor que a[i] encontrou seu próximo maior: é ele. Esses índices saem da pilha, e i entra. Para {4, 5, 2, 10, 8}, o resultado é {5, 10, 10, −1, −1}.

Por que é O(n) e não O(n²): cada índice entra na pilha uma vez e sai no máximo uma vez.

Em C · 07-pilhas.c · ex:proximo-maior

static void proximo_maior(const int a[], int res[], size_t n) {
    Pilha p;
    pilha_iniciar(&p);                           /* guarda índices, valores decrescentes */
    for (size_t i = 0; i < n; i++) res[i] = -1;
    for (size_t i = 0; i < n; i++) {
        int j = 0;
        while (peek(&p, &j) && a[j] < a[i]) {
            pop(&p, &j);
            res[j] = a[i];
        }
        push(&p, (int)i);
    }
}

Exercício 3: remover pares adjacentes iguais

Enunciado. Em uma string, remova pares de caracteres iguais adjacentes, repetidamente, até não restar nenhum. Por exemplo, "abbaca" vira "ca".

Ideia. Processe os caracteres da esquerda para a direita, mantendo na pilha o resultado parcial. Se o caractere atual é igual ao topo, o par se cancela: desempilhe. Senão, empilhe. A remoção em cascata acontece sozinha, porque após um cancelamento, o novo topo é comparado com o próximo caractere.

Complexidade: O(n) de tempo, O(n) de espaço.

Em C · 07-pilhas.c · ex:remover-pares

static size_t remover_adjacentes(const char *s, char *out) {
    Pilha p;
    pilha_iniciar(&p);
    for (const char *c = s; *c; c++) {
        int t;
        if (peek(&p, &t) && t == *c) pop(&p, &t);
        else push(&p, *c);
    }
    size_t n = 0;
    for (int i = 0; i <= p.topo; i++) out[n++] = (char)p.d[i];
    out[n] = '\0';
    return n;
}

Exemplo A: Avaliação de expressões com duas pilhas

Uma pilha guarda valores e outra operadores; a precedência decide quando aplicar cada operador. 2 + 3·(4 − 1) resulta em 11.

Em C · 07-mais-exemplos.c · ex-a

static int prec(char op) { return (op == '+' || op == '-') ? 1 : 2; }

static void aplicar(Pilha *vals, Pilha *ops) {
    int b = pop(vals), a = pop(vals);
    char op = (char)pop(ops);
    push(vals, op == '+' ? a + b : op == '-' ? a - b : a * b);
}

static int avaliar(const char *s) {
    Pilha vals, ops;
    iniciar(&vals);
    iniciar(&ops);
    for (const char *p = s; *p; p++) {
        if (isdigit((unsigned char)*p)) {
            int v = 0;
            while (isdigit((unsigned char)*p)) v = v * 10 + (*p++ - '0');
            p--;
            push(&vals, v);
        } else if (*p == '(') {
            push(&ops, '(');
        } else if (*p == ')') {
            while (!vazia(&ops) && ops.d[ops.topo] != '(') aplicar(&vals, &ops);
            pop(&ops);
        } else if (*p == '+' || *p == '-' || *p == '*') {
            while (!vazia(&ops) && ops.d[ops.topo] != '(' && prec(ops.d[ops.topo]) >= prec(*p))
                aplicar(&vals, &ops);
            push(&ops, *p);
        }
    }
    while (!vazia(&ops)) aplicar(&vals, &ops);
    return pop(&vals);
}

Exemplo B: Maior retângulo em histograma

Pilha monotônica crescente de índices. Ao fechar uma barra, calcula-se a área com ela como altura mínima. Cada barra entra e sai uma vez: O(n).

Em C · 07-mais-exemplos.c · ex-b

static long maior_retangulo(const int h[], int n) {
    Pilha p;
    iniciar(&p);
    long melhor = 0;
    for (int i = 0; i <= n; i++) {
        int atual = (i == n) ? 0 : h[i];
        while (!vazia(&p) && h[p.d[p.topo]] >= atual) {
            int alt = h[pop(&p)];
            int larg = vazia(&p) ? i : i - p.d[p.topo] - 1;
            long area = (long)alt * larg;
            if (area > melhor) melhor = area;
        }
        push(&p, i);
    }
    return melhor;
}

Exemplo C: Decodificar strings aninhadas

A pilha de níveis guarda o texto acumulado e a contagem de cada colchete. "3[ab2[c]]" vira "abccabccabcc".

Em C · 07-mais-exemplos.c · ex-c

static void decodificar(const char *s, char saida[]) {
    int cont[MAX];
    char texto[MAX][MAX];
    int nivel = 0;
    cont[0] = 1;
    texto[0][0] = '\0';
    for (const char *p = s; *p; p++) {
        if (isdigit((unsigned char)*p)) {
            cont[nivel + 1] = 0;
            while (isdigit((unsigned char)*p)) cont[nivel + 1] = cont[nivel + 1] * 10 + (*p++ - '0');
            p--;
        } else if (*p == '[') {
            nivel++;
            texto[nivel][0] = '\0';
        } else if (*p == ']') {
            char bloco[MAX * 4] = "";
            for (int k = 0; k < cont[nivel]; k++) strcat(bloco, texto[nivel]);
            nivel--;
            strcat(texto[nivel], bloco);
        } else {
            size_t t = strlen(texto[nivel]);
            texto[nivel][t] = *p;
            texto[nivel][t + 1] = '\0';
        }
    }
    strcpy(saida, texto[0]);
}

Exemplo D: A sequência de saídas é possível?

Simula push e pop: para cada valor esperado na saída, ou ele já está no topo, ou é empilhado até chegar. {4, 5, 3, 2, 1} é possível; {3, 5, 4, 1, 2} não é.

Em C · 07-mais-exemplos.c · ex-d

static int sequencia_possivel(const int entrada[], const int saida[], int n) {
    Pilha p;
    iniciar(&p);
    int i = 0;
    for (int k = 0; k < n; k++) {
        while (vazia(&p) || p.d[p.topo] != saida[k]) {
            if (i == n) return 0;
            push(&p, entrada[i++]);
        }
        pop(&p);
    }
    return 1;
}

Conceitos complementares e uso no dia a dia

Conceitos complementares

  • Pilha de chamadas: cada chamada de função ocupa um quadro na pilha de execução. Recursão profunda demais esgota essa pilha e causa o erro de stack overflow.
  • Pilha explícita versus recursão: qualquer recursão pode ser convertida em um laço com pilha própria. Isso é útil quando a profundidade é grande demais para a pilha do sistema.
  • Análise de expressões: compiladores transformam código em árvores de sintaxe usando pilhas, com precedência de operadores.
  • Backtracking: a pilha de escolhas é o que permite desfazer uma decisão ruim e tentar a seguinte, como no problema das rainhas.

Onde isso aparece no dia a dia

  • Desfazer (Ctrl+Z): cada ação é empilhada; desfazer é desempilhar. Refazer usa uma segunda pilha, como na página de pilhas.
  • Botão voltar do navegador: as páginas visitadas formam uma pilha. Voltar desempilha a página atual.
  • Validação de código e de HTML: editores destacam parênteses e tags não fechadas com uma pilha, que é exatamente o exemplo de casamento.
  • Calculadoras: expressões com parênteses e precedência são avaliadas com pilhas, como nas calculadoras científicas mais antigas em notação polonesa reversa.

Pilha de chamadas, tipos de pilha e erros comuns

Pilha de chamadas: onde a pilha está escondida

Toda chamada de função empilha um quadro com endereço de retorno, parâmetros e variáveis locais. Quando a função retorna, o quadro é desempilhado. Por isso, uma recursão com profundidade 100 000 pode esgotar a memória da pilha do sistema e causar um stack overflow, mesmo que o algoritmo esteja correto. A solução costuma ser converter a recursão em laço com uma pilha explícita, que vive no heap e cresce até o limite da memória.

Tipos de pilha que você vai encontrar

  • Pilha de valores e de operadores (como nas expressões acima): duas pilhas trabalham juntas.
  • Pilha monotônica: mantém valores em ordem crescente ou decrescente para responder "próximo maior" em O(n).
  • Pilhas de desfazer e refazer: a pilha de desfazer recebe cada ação; desfazer tira dela e coloca na pilha de refazer.
  • Pilha de execução: gerenciada pelo sistema, com tamanho limitado.

Erros comuns com pilhas em C

  • Underflow: pop em pilha vazia. Sempre checar antes de usar o valor.
  • Overflow: push sem checar a capacidade do vetor fixo.
  • Não verificar pilha vazia no fim: em parênteses, aberturas sobrando significam expressão inválida.
  • Comparar só quantidades no casamento de parênteses: a ordem e o tipo dos pares precisam ser verificados.
  • Ignorar o retorno de pop e push: a função devolve 0 para avisar falha, e ignorar isso mascara o erro.

Animação: desfazer e refazer com duas pilhas

O botão desfazer é uma pilha. Cada ação é empilhada e cada desfazer a move para a pilha de refazer.

Exercícios propostos

P1. Como você adaptaria a avaliação de RPN para aceitar números com mais de um dígito e operadores de potência?

Resposta: o código já acumula dígitos em v; a potência é um operador a mais no switch, com o cuidado de que expoentes negativos produzem frações, então o tipo precisa mudar. Para um código seguro, valide o domínio antes de calcular.

P2. Uma pilha de navegador guarda as páginas visitadas. Como modelar “voltar” e “avançar” com duas pilhas?

Resposta: a pilha de trás guarda as páginas anteriores; a pilha de frente guarda as páginas desfeitas. Voltar desempilha de trás e empilha na frente; avançar faz o contrário. Visitar uma nova página esvazia a pilha de frente.

Teste seus conhecimentos

Qual o resultado de 5 1 2 + 4 * + 3 - em notação pós-fixa?

Correto. 1 + 2 = 3; 3 · 4 = 12; 5 + 12 = 17; 17 − 3 = 14. É a expressão 5 + (1 + 2) · 4 − 3.

Por que a expressão {(}) é inválida, mesmo tendo igual número de aberturas e fechamentos?

Correto. A ordem dos pares é o que importa, e a pilha é a estrutura que registra essa ordem.

Qual o custo de push e pop em um vetor com ponteiro para o topo?

Correto. Operam apenas no topo, sem deslocamento de elementos.
