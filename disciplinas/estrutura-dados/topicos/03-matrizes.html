Tópico 3 · Matrizes

Uma matriz é um vetor indexado por duas coordenadas. Imagens, tabelas, grafos representados por adjacência, programação dinâmica e transformações geométricas são matrizes. A memória do computador é linear, então toda matriz é, por baixo, um vetor com uma fórmula de índice. Entender essa fórmula explica o custo dos percursos e a eficiência do cache.

Objetivos desta página. Ao final, você deve conseguir:

  • calcular a posição linear de (i, j) em uma matriz linha-maior;
  • implementar percursos, transposta e multiplicação de matrizes em C, com custos explícitos;
  • resolver problemas de percurso em espiral, rotação in place e marcação de linhas e colunas.

Teoria: a fórmula do índice

Uma matriz de L linhas e C colunas ocupa L · C posições contíguas. Na convenção linha-maior (row-major), usada por C, a linha 0 vem inteira, depois a linha 1, e assim por diante. Então a posição linear de (i, j) é:

k = i · C + j

A convenção coluna-maior (column-major), usada por Fortran e MATLAB, faz o oposto. As duas dão o mesmo resultado lógico, mas custos físicos diferentes: percorrer na ordem da memória é mais rápido (HENNESSY; PATTERSON, 2017, cap. 2). Em C, int m[L][C] é um único bloco contínuo, e essa garantia faz parte da linguagem (KERNIGHAN; RITCHIE, 1988, cap. 5).

Operação 1 · Percursos por linha e por coluna

Os dois percursos somam as mesmas células, então a complexidade é a mesma: O(L · C). A diferença está no padrão de acesso à memória. Percorrer por linhas visita posições consecutivas (k = 0, 1, 2, …), que cabem nas mesmas linhas de cache. Percorrer por colunas salta C posições a cada passo, e cada salto costuma trazer um bloco novo do cache. A animação mostra os dois padrões.

Em C · 03-matrizes.c · op:acessar

static int mat_get(const Matriz *m, size_t i, size_t j) {
    return m->d[i * m->col + j];              /* posição linear k = i·col + j */
}

static void mat_set(Matriz *m, size_t i, size_t j, int x) {
    m->d[i * m->col + j] = x;
}

Em C · 03-matrizes.c · op:percurso-linha

static long soma_por_linhas(const Matriz *m) {
    long s = 0;
    for (size_t i = 0; i < m->lin; i++)
        for (size_t j = 0; j < m->col; j++)
            s += mat_get(m, i, j);            /* acessos consecutivos na memória */
    return s;
}

Em C · 03-matrizes.c · op:percurso-coluna

static long soma_por_colunas(const Matriz *m) {
    long s = 0;
    for (size_t j = 0; j < m->col; j++)
        for (size_t i = 0; i < m->lin; i++)
            s += mat_get(m, i, j);            /* saltos de 'col' posições */
    return s;
}

Operação 2 · Transposta e produto

A transposta troca linhas por colunas: t[j][i] = a[i][j]. Ela precisa de uma matriz nova, porque a forma muda de L×C para C×L. O produto C = A·B tem três laços aninhados: para cada célula de C, somamos o produto de uma linha de A por uma coluna de B. Com matrizes n × n, o custo é O(n³), e isso motiva algoritmos mais sofisticados, como o de Strassen, que chega a O(n2,81) (CORMEN et al., 2022, cap. 4).

Em C · 03-matrizes.c · op:transposta

static int mat_transposta(const Matriz *a, Matriz *t) {
    if (!mat_criar(t, a->col, a->lin)) return 0;
    for (size_t i = 0; i < a->lin; i++)
        for (size_t j = 0; j < a->col; j++)
            mat_set(t, j, i, mat_get(a, i, j));
    return 1;
}

Em C · 03-matrizes.c · op:multiplicar

static int mat_multiplicar(const Matriz *a, const Matriz *b, Matriz *c) {
    if (a->col != b->lin) return 0;
    if (!mat_criar(c, a->lin, b->col)) return 0;
    for (size_t i = 0; i < a->lin; i++)
        for (size_t j = 0; j < b->col; j++) {
            int s = 0;
            for (size_t k = 0; k < a->col; k++)
                s += mat_get(a, i, k) * mat_get(b, k, j);
            mat_set(c, i, j, s);
        }
    return 1;
}
Padrão: quando a estrutura é regular (sempre um produto de linha por coluna), escreva primeiro a fórmula da célula c[i][j] e só depois os laços. Isso evita erros de índice.

Criação e liberação de memória

Em C, uma matriz dinâmica é um bloco único alocado com calloc (já zerado) e acessado pela fórmula do índice. Isso é mais eficiente e mais simples do que um vetor de ponteiros para vetores, porque há uma só alocação e nenhuma indireção extra. Cada calloc precisa de um free correspondente, senão há vazamento de memória.

Em C · 03-matrizes.c · op:criar

static int mat_criar(Matriz *m, size_t lin, size_t col) {
    m->d = calloc(lin * col, sizeof *m->d);   /* já zerada */
    if (m->d == NULL) return 0;
    m->lin = lin;
    m->col = col;
    return 1;
}

Animação: percurso em espiral

Cada volta visita a borda da camada atual e então reduz os quatro limites. Observe como o percurso fecha uma camada de cada vez.

Padrões de resolução com matrizes

Limites que encolhem

Espiral e percursos em camadas: quatro limites (topo, base, esquerda, direita) que avançam a cada borda visitada.

Transpor e inverter

Rotação de 90° = transposta seguida da inversão de cada linha. Mesma ideia da rotação de vetores.

Marcar e depois agir

Primeiro registre as linhas e colunas afetadas, depois altere. Não altere enquanto percorre, senão a própria marcação se contamina.

Soma por diagonal

Em matrizes quadradas, a diagonal principal é (i, i) e a secundária é (i, n − 1 − i). Cuidado com o centro, contado duas vezes.

Exercícios resolvidos

Exercício 1: percurso em espiral

Enunciado. Devolva os elementos de uma matriz L × C na ordem de uma espiral que começa no canto superior esquerdo e vai para dentro.

Padrão: limites que encolhem. Mantemos topo, base, esq e dir. Cada etapa percorre um lado e encolhe o limite correspondente. As condições if evitam percorrer a mesma linha ou coluna duas vezes quando a matriz tem uma só linha ou coluna restante.

Complexidade: O(L · C) de tempo, O(1) de espaço extra (sem contar a saída).

Em C · 03-matrizes.c · ex:espiral

static size_t espiral(const Matriz *m, int saida[]) {
    size_t topo = 0, base = m->lin, esq = 0, dir = m->col, n = 0;
    while (topo < base && esq < dir) {
        for (size_t j = esq; j < dir; j++) saida[n++] = mat_get(m, topo, j);
        topo++;
        for (size_t i = topo; i < base; i++) saida[n++] = mat_get(m, i, dir - 1);
        dir--;
        if (topo < base) {
            for (size_t j = dir; j > esq; j--) saida[n++] = mat_get(m, base - 1, j - 1);
            base--;
        }
        if (esq < dir) {
            for (size_t i = base; i > topo; i--) saida[n++] = mat_get(m, i - 1, esq);
            esq++;
        }
    }
    return n;
}

Exercício 2: rotacionar uma matriz quadrada em 90° in place

Enunciado. Gire uma matriz n × n no sentido horário, sem alocar outra.

Ideia. Na rotação horária, a linha i vira a coluna n − 1 − i. Isso se decompõe em duas operações mais simples: primeiro transpor (linhas viram colunas, (i,j) ↔ (j,i)), depois inverter cada linha. Exemplo: a primeira linha [1,2,3] vira coluna, e a inversão a coloca na última coluna.

Complexidade: O(n²) de tempo, O(1) de espaço.

Em C · 03-matrizes.c · ex:rotacionar90

static void rotacionar90(Matriz *m) {                 /* quadrada, sentido horário */
    size_t n = m->lin;
    for (size_t i = 0; i < n; i++)                     /* 1) transpõe in place */
        for (size_t j = i + 1; j < n; j++) {
            int t = mat_get(m, i, j);
            mat_set(m, i, j, mat_get(m, j, i));
            mat_set(m, j, i, t);
        }
    for (size_t i = 0; i < n; i++)                     /* 2) inverte cada linha */
        for (size_t a = 0, b = n - 1; a < b; a++, b--) {
            int t = mat_get(m, i, a);
            mat_set(m, i, a, mat_get(m, i, b));
            mat_set(m, i, b, t);
        }
}

Exercício 3: zerar linhas e colunas

Enunciado. Se uma célula é zero, zere toda a sua linha e toda a sua coluna.

Padrão: marcar e depois agir. Se zerássemos durante a varredura, um zero novo poderia ser encontrado depois e zerar linhas que não deveriam ser zeradas. Por isso guardamos dois vetores de marcas (uma por linha, uma por coluna) e só então alteramos.

Complexidade: O(L · C) de tempo; O(L + C) de espaço extra para as marcas.

Em C · 03-matrizes.c · ex:zeros

static void zerar_linhas_colunas(Matriz *m) {
    unsigned char *linha = calloc(m->lin, 1);
    unsigned char *coluna = calloc(m->col, 1);
    if (linha == NULL || coluna == NULL) {
        free(linha);
        free(coluna);
        return;
    }
    for (size_t i = 0; i < m->lin; i++)
        for (size_t j = 0; j < m->col; j++)
            if (mat_get(m, i, j) == 0) {
                linha[i] = 1;
                coluna[j] = 1;
            }
    for (size_t i = 0; i < m->lin; i++)
        for (size_t j = 0; j < m->col; j++)
            if (linha[i] || coluna[j]) mat_set(m, i, j, 0);
    free(linha);
    free(coluna);
}

Exercício 4: soma das diagonais

Enunciado. Some as diagonais principal e secundária de uma matriz quadrada, sem contar o centro duas vezes em matrizes de ordem ímpar.

Ideia. A diagonal principal é (i, i); a secundária é (i, n−1−i). Um único laço percorre i de 0 a n−1 e soma as duas. O centro de uma matriz ímpar aparece nas duas, então a segunda soma só acontece quando k ≠ i.

Complexidade: O(n) de tempo, O(1) de espaço, já que a matriz é quadrada e tem n² células, mas só n são somadas.

Em C · 03-matrizes.c · ex:diagonais

static long soma_diagonais(const Matriz *m) {
    long s = 0;
    for (size_t i = 0; i < m->lin; i++) {
        s += mat_get(m, i, i);
        size_t k = m->lin - 1 - i;
        if (k != i) s += mat_get(m, i, k);      /* o centro não é contado duas vezes */
    }
    return s;
}

Exercícios propostos

P1. Dada uma matriz de inteiros com linhas e colunas ordenadas crescentemente, encontre se um valor existe, em tempo O(L + C).

Resposta: comece no canto superior direito. Se o valor atual é maior que o alvo, a coluna inteira é descartada (andamos uma coluna para a esquerda); se é menor, a linha inteira é descartada (descemos uma linha). Cada passo elimina uma linha ou uma coluna.

P2. Calcule o custo de multiplicar uma matriz 100 × 200 por uma 200 × 50, em número de multiplicações escalares.

Resposta: L · K · C = 100 · 200 · 50 = 1 000 000 multiplicações. Note que a ordem das matrizes importa: multiplicar 200 × 50 por 100 × 200 não é possível, porque o número de colunas precisa coincidir com o de linhas.

Teste seus conhecimentos

Em uma matriz linha-maior com 4 colunas, qual é a posição linear de (2, 1)?

Correto: k = i · C + j = 2 · 4 + 1 = 9, com índices começando em zero, como em C.

Qual percurso tende a ser mais rápido em C, e por quê?

Correto. A ordem de acesso coincide com a ordem física, e a localidade espacial faz o cache trazer blocos úteis.

Qual o custo de multiplicar duas matrizes n × n pelo método direto?

Correto. São três laços aninhados de n passos: n · n · n operações.

O que levar desta página

  • Em C, toda matriz é um bloco linear; o índice é i · C + j.
  • Acesso é O(1); percorrer tudo é O(L · C), e a ordem do percurso afeta o cache.
  • Transposta e rotação são operações de reorganização; a rotação in place combina transposta com inversões.
  • Problemas de espiral e de marcação usam limites que encolhem e marcas auxiliares.
