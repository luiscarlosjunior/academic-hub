Tópico 3 · Autômatos finitos determinísticos

Um autômato finito determinístico (AFD) é o modelo de computação mais simples que estudamos. Ele lê uma cadeia da esquerda para a direita, uma letra por vez, e tem memória limitada a um único estado. Ao final, aceita ou rejeita.

Apesar da simplicidade, os AFDs aparecem em todo lugar: analisadores léxicos de compiladores, validação de formatos, protocolos de comunicação e controladores de hardware. Eles são o ponto de partida natural para entender autômatos mais poderosos.

Definição formal

Um AFD é uma quíntupla M = (Q, Σ, δ, q0, F), em que:

  • Q é um conjunto finito de estados;
  • Σ é o alfabeto de entrada;
  • δ: Q × Σ → Q é a função de transição total (para cada estado e cada símbolo, existe exatamente um próximo estado);
  • q0 ∈ Q é o estado inicial;
  • F ⊆ Q é o conjunto de estados de aceitação.

Uma cadeia w = a1a2…an é aceita se existe uma sequência de estados r0, r1, …, rn com r0 = q0, ri = δ(ri-1, ai) e rn ∈ F. A linguagem de M, L(M), é o conjunto das cadeias aceitas.

Exemplo: projetando um AFD

Queremos o AFD para L = {w ∈ {0,1}* | w termina com 01}. A ideia é pensar no que o autômato precisa lembrar sobre o que já leu:

  • q0: "o último símbolo não é 0" (ou ainda não lemos nada útil). É inicial.
  • q1: "o último símbolo é 0". Ainda pode faltar um 1.
  • q2: "as duas últimas letras são 01". É o único estado de aceitação.

As transições seguem da mesma lógica. De q1, um 0 mantém a informação "último é 0", e um 1 leva a q2. De q2, um 0 volta a q1 e um 1 forma "11", que volta a q0.

Simulação em código

Um AFD se simula com uma tabela e um laço. O código abaixo implementa o autômato do exemplo; a parte que mais importa é que cada letra é lida exatamente uma vez.

delta = {
    ("q0", "0"): "q1", ("q0", "1"): "q0",
    ("q1", "0"): "q1", ("q1", "1"): "q2",
    ("q2", "0"): "q1", ("q2", "1"): "q0",
}
F = {"q2"}

def aceita(w):
    estado = "q0"
    for simbolo in w:
        estado = delta[(estado, simbolo)]
    return estado in F

print(aceita("1101"))   # True
print(aceita("0110"))   # False

Animação: o AFD processando 1101

Avance passo a passo para ver o estado mudar a cada letra. No fim, o autômato está em q2, que é de aceitação.

Práticas

  1. Projete um AFD para {w ∈ {a,b}* | |w| é par}. Quantos estados são necessários?
  2. Projete um AFD para {w ∈ {0,1}* | w contém 000 como subcadeia}.
  3. Simule o AFD do exemplo sobre a cadeia 0101 e liste a sequência de estados visitados.
