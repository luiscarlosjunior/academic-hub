Tópico 5 · Expressões regulares e o teorema de Kleene

Expressões regulares são a forma declarativa de descrever linguagens regulares. Enquanto um AFD diz como reconhecer uma cadeia, uma expressão regular diz qual é o padrão. É a notação de buscas em editores, do grep e de validadores de entrada.

O teorema de Kleene afirma que expressões regulares, AFDs e AFNs descrevem exatamente a mesma classe de linguagens. Essa equivalência é o que permite trocar de notação conforme a conveniência.

Sintaxe e semântica

Uma expressão regular sobre Σ é definida recursivamente:

  • ∅ é uma expressão que denota a linguagem vazia; ε denota {ε}; cada símbolo a ∈ Σ denota {a}.
  • união: (R + S) denota L(R) ∪ L(S);
  • concatenação: (RS) denota L(R)L(S);
  • estrela: R* denota L(R)*, ou seja, zero ou mais repetições.

Convenções: a estrela tem precedência sobre a concatenação, e a concatenação sobre a união. Assim, ab*+c significa (a(b*)) + c.

Exemplos de padrões

ExpressãoLinguagemExemplos de cadeias
(0 + 1)*Todas as cadeias bináriasε, 0, 10110
(0 + 1)*11Terminam em 1111, 0111 (não: 0110)
a*b*Blocos de a seguidos de bε, aab, bbb (não: aba)
(01)*Repetições do bloco 01ε, 01, 0101 (não: 010)

Repare que as expressões são "ambíguas" em um sentido útil: uma mesma cadeia pode casar de várias maneiras, mas o que importa para a linguagem é só se existe alguma casagem.

O teorema de Kleene

O teorema tem duas direções, e ambas são construtivas:

  1. Expressão → autômato: para cada expressão R existe um AFN com ε-transições que reconhece L(R). A construção de Thompson faz isso com um pequeno "bloco" para cada operador, emendados por ε-transições.
  2. Autômato → expressão: para cada AFD existe uma expressão que descreve sua linguagem. O método de eliminação de estados remove os estados um a um e combina os rótulos das arestas com união, concatenação e estrela.

A primeira direção é a que aparece no dia a dia: é ela que um compilador usa para transformar um padrão de token em um reconhecedor eficiente.

Animação: de a*b a um autômato

A expressão a*b é montada a partir de blocos pequenos: um bloco para a, um para a*, um para b e, por fim, a concatenação. Acompanhe a montagem passo a passo.

Formalização: do autômato à expressão

A parte "autômato → expressão" do teorema de Kleene pode ser feita por equações de linguagens. Para isso, precisamos de uma ferramenta algébrica.

Lema de Arden

Lema. Sejam A, B ⊆ Σ*, com ε ∉ A. A equação em X, X = AX ∪ B, tem solução única X = A*B.

Prova. Verificamos que A*B é solução: AA*B ∪ B = (AA* ∪ {ε})B = A*B. Para unicidade, suponha que X satisfaça X = AX ∪ B. Substituindo repetidamente, X = B ∪ AB ∪ A²X = … = AiB ∪ … ∪ B ∪ Ai+1X, para todo i. Como ε ∉ A, cada cadeia de Ai+1X tem comprimento pelo menos i + 1. Assim, toda cadeia de X está em algum AiB, e X ⊆ A*B. A inclusão contrária já vale. ∎

Sistema de equações para um AFD

Para cada estado q, seja Xq a linguagem das cadeias que levam de q a algum estado final. Então:

X_q = ∪_{a ∈ Σ, δ(q,a)=p} a · X_p   ∪   (ε, se q ∈ F)

Resolvendo o sistema por substituição e pelo lema de Arden, obtemos Xq₀ como expressão regular. Essa é a eliminação de estados em forma algébrica.

Equivalência de tamanhos

A construção de Thompson gera um AFN com O(|R|) estados para uma expressão R de tamanho |R|, pois cada operador acrescenta um número constante de estados e transições ε. Na direção inversa, a eliminação de estados pode gerar expressões de tamanho exponencial em n, o que mostra que a conversão AFD → expressão não é, em geral, polinomial no número de estados. Essa assimetria de tamanhos é um tema recorrente em complexidade descritiva.
