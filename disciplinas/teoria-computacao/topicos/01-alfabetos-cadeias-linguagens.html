Tópico 1 · Alfabetos, cadeias e linguagens

A teoria da computação começa com uma decisão de modelagem: antes de falar de programas, computadores ou algoritmos, reduzimos a informação a símbolos e sequências de símbolos. Uma senha, um número escrito em binário, um programa-fonte e uma molécula em notação textual são todos cadeias sobre algum alfabeto.

Essa redução parece pobre, mas não custa poder. Qualquer entrada finita de um computador pode ser codificada como uma cadeia binária, e a pergunta "este número é primo?" vira "esta cadeia pertence ao conjunto dos codificados de números primos?". Por isso, o estudo do que um computador consegue fazer se torna o estudo de linguagens formais.

Alfabeto e cadeias

Um alfabeto Σ é um conjunto finito e não vazio de símbolos. Exemplos: Σ = {0, 1} (binário), Σ = {a, b, c} e o alfabeto latino com pontuação.

Uma cadeia (ou palavra) sobre Σ é uma sequência finita de símbolos de Σ. O comprimento de uma cadeia w, escrito |w|, é o número de símbolos. A cadeia de comprimento zero é a cadeia vazia, escrita ε (épsilon).

  • Com Σ = {0, 1}, as cadeias 0, 1, 01, 110 e ε são todas válidas; 2 não é, porque o símbolo 2 não está em Σ.
  • |110| = 3, |ε| = 0.
  • O conjunto de todas as cadeias sobre Σ é denotado Σ*. Ele é infinito, mas enumerável: podemos listar primeiro as cadeias de tamanho 0, depois de tamanho 1, depois de tamanho 2 e assim por diante.

A enumeração por tamanho e, dentro de cada tamanho, em ordem lexicográfica é o que torna possível percorrer todas as entradas possíveis de um problema. Esse fato vai reaparecer quando discutirmos máquinas de Turing.

Operações sobre cadeias

Sobre cadeias, definimos algumas operações simples que serão usadas o tempo todo:

  • Concatenação: xy é x seguido de y. Ex.: ab · ba = abba. A concatenação é associativa, mas não é comutativa, e ε é o elemento neutro.
  • Potência: xn é x repetido n vezes, com x0 = ε. Ex.: (ab)3 = ababab.
  • Reverso: wR é w lido de trás para frente. Ex.: (abc)R = cba.
  • Prefixo, sufixo e subcadeia: em abc, os prefixos são ε, a, ab, abc; os sufixos são ε, c, bc, abc.
w     = "abba"
|w|   = 4
w^R   = "abba"            (palíndromo)
w^2   = "abbaabba"
ε·w   = w                 (ε é neutro)

Linguagens formais

Uma linguagem sobre Σ é simplesmente um subconjunto L ⊆ Σ*. Não há nada de "linguagem natural" aqui: L pode ser infinita, vazia ou ter uma única cadeia.

Como linguagens são conjuntos, podemos usar as operações de conjuntos (união, interseção, complemento em relação a Σ*) e também operações próprias:

  • Concatenação de linguagens: L1L2 = {xy | x ∈ L1 e y ∈ L2}.
  • Fecho de Kleene: L* = {w1…wk | k ≥ 0 e cada wi ∈ L}. Note que L* sempre contém ε.

Atenção à notação: Σ* é o conjunto de todas as cadeias sobre Σ, enquanto L* é o fecho de uma linguagem L. Os dois usam o mesmo asterisco por herança, e o contexto indica qual é qual.

Problema de decisão como linguagem

O ponto central deste tópico é uma correspondência: um problema de decisão (uma pergunta com resposta sim ou não) é equivalente a uma linguagem. A pergunta vira o conjunto das entradas que respondem "sim".

Por exemplo, "o grafo G tem um caminho de comprimento 5 entre dois vértices?" corresponde à linguagem formada pelas codificações de pares (G, s, t) para os quais a resposta é sim. Resolver o problema é decidir, dada uma cadeia w, se w ∈ L.

PAR = { w ∈ {0,1}* | w tem um número par de 1s }

ε ∈ PAR      (zero 1s, que é par)
0110 ∈ PAR   (dois 1s)
011 ∉ PAR    (três 1s)

Essa tradução é o que permite falar de todos os problemas com a mesma linguagem: autômatos, gramáticas, máquinas de Turing e classes de complexidade são todos definidos a partir de linguagens.

Animação: decidindo PAR símbolo a símbolo

Para decidir se uma cadeia pertence a PAR, basta contar a paridade dos 1s lidos. O player mostra o estado (paridade acumulada) mudando a cada símbolo.

Práticas

  1. Liste todas as cadeias de Σ* com |w| ≤ 2 para Σ = {a, b}. Quantas são?
  2. Descreva em português a linguagem {w ∈ {0,1}* | w começa e termina com o mesmo símbolo}. Dê cinco cadeias que pertencem a ela e três que não pertencem.
  3. Mostre que, para quaisquer cadeias x e y, |xy| = |x| + |y| e (xy)R = yRxR.

Teste seus conhecimentos

Quantas cadeias de comprimento exatamente 3 existem sobre Σ = {0, 1}?

Correto. Cada posição pode receber 0 ou 1, então são 2 × 2 × 2 = 8 cadeias: 000, 001, …, 111.

A cadeia vazia ε pertence à linguagem PAR definida no tópico?

Correto. ε tem zero 1s, e zero é par. Além disso, ε pertence a todo Σ*, por definição.
