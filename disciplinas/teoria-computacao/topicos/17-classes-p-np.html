Tópico 17 · As classes P e NP

Se um problema tem solução em tempo polinomial, ele é tratável: escala para entradas grandes. Se a melhor solução conhecida leva tempo exponencial, ele parece intratável. A classe P reúne os primeiros; a classe NP reúne problemas cujas soluções podem ser verificadas em tempo polinomial, mesmo que encontrá-las pareça muito mais difícil.

A pergunta central da área, P = NP?, pergunta se verificar é sempre tão fácil quanto encontrar. É um dos sete Problemas do Milênio do Clay Mathematics Institute, com prêmio de um milhão de dólares.

A classe P

P é o conjunto de linguagens decididas por uma MT determinística em tempo polinomial: P = ∪k DTIME(nk). São exemplos clássicos:

  • ordenação, busca em grafos (BFS e DFS), caminho mínimo (Dijkstra);
  • emparelhamento máximo em grafos bipartidos e fluxo máximo;
  • teste de primalidade (AKS, 2002), que decide se um número é primo em tempo polinomial no número de dígitos.

A classe NP e os verificadores

Um verificador V para uma linguagem L é uma MT que recebe a entrada w e um certificado c, e satisfaz:

  • se w ∈ L, existe c tal que V(w, c) aceita;
  • se w ∉ L, nenhum c faz V aceitar;
  • V para em tempo polinomial em |w|, e |c| é polinomial em |w|.

NP é o conjunto das linguagens com um verificador polinomial. De forma equivalente, NP é o conjunto de linguagens decididas por MTs não determinísticas em tempo polinomial: a MT "adivinha" o certificado e depois verifica.

P ⊆ NP, porque um decisor polinomial é um verificador que ignora o certificado. A questão é se a inclusão é própria.

A questão em aberto

Ninguém sabe se P = NP. Se fosse verdade, existiria um algoritmo polinomial para SAT, e com ele para milhares de problemas práticos (logística, escalonamento, criptoanálise de vários sistemas). A opinião dominante entre especialistas é que P ≠ NP, mas esse consenso não é prova, e o tópico 20 discute por que a prova é tão difícil.

Uma observação útil: se P ≠ NP, ainda há uma enorme hierarquia de problemas com graus de dificuldade diferentes dentro de NP. O próximo tópico mostra os mais difíceis deles, os NP-completos.

Animação: verificando SAT

Fórmula: (x₁ ∨ x₂) ∧ (¬x₁ ∨ x₃) ∧ (¬x₂ ∨ ¬x₃). Encontrar uma atribuição é difícil em geral; verificar uma dada é rápido. O certificado é x₁ = 1, x₂ = 0, x₃ = 1.

Formalização: NP por verificadores e por NTIME

Definições

NTIME(f) = { L | existe MT não determinística N que decide L com todo ramo de comprimento ≤ f(|x|) }
NP       = ⋃_k NTIME(n^k)
NP       = { L | existe verificador V e polinômio p com
             x ∈ L ⇔ ∃ c, |c| ≤ p(|x|) e V(x, c) aceita, V de tempo polinomial }

Teorema. As duas definições de NP coincidem.

Prova. (⇐ direção de verificador para NTIME) Uma MT não determinística escreve c, com |c| ≤ p(n), na fita, usando seu não determinismo (cada símbolo é uma escolha), e depois executa V. Todo ramo tem tempo polinomial. (⇒) Seja N não determinística com ramos de tamanho ≤ q(n). Um certificado é a sequência de escolhas feitas por N, que tem comprimento ≤ q(n) bits. O verificador simula N seguindo as escolhas indicadas em c e aceita se o ramo aceita. ∎

P ⊆ NP ⊆ EXPTIME

Proposição. NP ⊆ EXPTIME.

Prova. Se L está em NP com verificador V de tempo nk e certificados de tamanho ≤ p(n), então, para entrada x de tamanho n, enumeramos os 2p(n)+1 − 1 certificados possíveis e rodamos V sobre cada um. O tempo total é 2p(n) · poly(n), que é exponencial. ∎

Note que a inclusão P ⊆ NP é imediata: um decisor determinístico polinomial é um verificador que ignora o certificado.

Um verificador com prova

Caminho hamiltoniano (HAMPATH) está em NP: o certificado é uma permutação π dos vértices, de tamanho O(n log n) bits. O verificador confere, para cada i, se {π(i), π(i+1)} é aresta, e se π é uma permutação (cada vértice aparece exatamente uma vez). Ambas as checagens levam tempo polinomial. Logo HAMPATH ∈ NP.

Questão em aberto, formalmente

P = NP é equivalente a: para toda L ∈ NP existe decisor determinístico polinomial. Como a classe NP é definida por ∃ sobre certificados polinomiais e P não tem quantificadores, a questão é se ∃ pode ser eliminado em tempo polinomial. A equivalência com NP = coNP é também em aberto, pois coNP usa ∀ sobre certificados.

Teste seus conhecimentos

O que define um problema estar em NP?

Correto. Essa é a caracterização por verificadores. NP não exige que a solução seja fácil de encontrar, só fácil de conferir.

Se algum problema NP-completo (como SAT) fosse resolvido em tempo polinomial, o que se concluiria?

Correto. Como todo problema de NP se reduz em tempo polinomial a um problema NP-completo (tópico 18), uma solução polinomial para ele daria uma solução polinomial para toda NP.
