O valor devolvido pelo executeUpdate

executeUpdate() devolve o número de linhas alteradas. É a única forma de saber se o comando encontrou alguma coisa: um UPDATE ... WHERE id = 999 não lança erro, apenas devolve 0.

Animação: a atualização condicional

O método atualizarPrecoSeIgual só altera o preço se ele ainda for o que o usuário viu. Acompanhe as duas tentativas do exemplo: a primeira combina com o banco, a segunda não.

Passo a passo animado

O código abaixo é um trecho real do projeto. Avance com os botões ou use Animar: a linha em execução é destacada e a explicação acompanha.

public boolean atualizarPrecoSeIgual(long id, double precoEsperado, double novoPreco) throws SQLException {
    String sql = "UPDATE livro SET preco = ? WHERE id = ? AND preco = ?";
    try (PreparedStatement ps = con.prepareStatement(sql)) {
        ps.setDouble(1, novoPreco);
        ps.setLong(2, id);
        ps.setDouble(3, precoEsperado);
        return ps.executeUpdate() == 1;
    }
}

Controle otimista na prática

Dois atendentes leem o mesmo preço. Se ambos gravarem sem verificar, o segundo apaga a mudança do primeiro sem saber. A solução é incluir o valor lido na condição: WHERE id = ? AND preco = ?. Se o preço já mudou, a linha não casa, o número de linhas é 0, e a aplicação pede que o usuário recarregue.

Remover e verificar

Para remover, confira o número de linhas. Um DELETE de id inexistente não é erro: a aplicação deve informar isso ao usuário. Se uma chave estrangeira impedir a remoção, o banco lança SQLException (código 19).

Exemplo executável: atualizar, comparar e remover

A demonstração atualiza o preço, testa um id inexistente, faz as duas atualizações condicionais, remove o livro e tenta remover de novo.

package demos;

import biblioteca.Conexao;
import biblioteca.Livro;
import biblioteca.LivroDao;
import java.sql.Connection;
import java.util.List;

/** Tópico 5: atualizar (U) e remover (D), olhando o número de linhas afetadas. */
public class Demo05Atualizar {

    public static void main(String[] args) throws Exception {
        String arq = "demo05.db";
        new java.io.File(arq).delete();
        try (Connection con = Conexao.abrir(arq)) {
            Conexao.criarTabelas(con);
            LivroDao dao = new LivroDao(con);
            long id = dao.inserir(new Livro(null, "Vidas Secas", 1938, 24.5, "978-3"));

            System.out.println("== atualizar");
            boolean ok = dao.atualizar(new Livro(id, "Vidas Secas", 1938, 19.9, "978-3"));
            System.out.println("atualizou: " + ok + ", preço agora: " + dao.buscarPorId(id).get().preco());
            System.out.println("id inexistente: " + dao.atualizar(new Livro(999L, "X", 2000, 1, null)));

            System.out.println("== atualização condicional");
            System.out.println("preço esperado 19.9 -> 17.0: " + dao.atualizarPrecoSeIgual(id, 19.9, 17.0));
            System.out.println("preço esperado 19.9 (já mudou) -> 15.0: " + dao.atualizarPrecoSeIgual(id, 19.9, 15.0));
            System.out.println("preço final: " + dao.buscarPorId(id).get().preco());

            System.out.println("== remover");
            System.out.println("primeira vez: " + dao.remover(id));
            System.out.println("segunda vez: " + dao.remover(id));
            System.out.println("total: " + dao.contar());
        }
        new java.io.File(arq).delete();
    }
}

Erros comuns

  • Ignorar o retorno do executeUpdate: o programa informa sucesso mesmo quando nada mudou.
  • Comparar decimais com == depois de cálculos: compare o valor com a mesma origem, ou trabalhe com centavos inteiros.
  • UPDATE sem WHERE: altera a tabela inteira.

Exercícios

1. Escreva aplicarDesconto(double percentual) que reduz o preço dos livros acima de 30.

Gabarito: UPDATE livro SET preco = preco * (1 - ?) WHERE preco > 30, com ps.setDouble(1, percentual / 100). O método devolve o executeUpdate(): quantos livros foram afetados.

2. Por que a segunda atualização condicional da demonstração devolveu false?

Gabarito: a primeira atualização já tinha mudado o preço para 17,00. A condição preco = 19.9 deixou de valer, nenhuma linha casou, e o retorno foi 0.
