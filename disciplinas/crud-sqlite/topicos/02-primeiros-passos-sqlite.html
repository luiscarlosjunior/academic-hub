Ter o SQLite disponível

Há três formas comuns de usar o SQLite, e você pode combiná-las:

  • Terminal: o programa sqlite3. No macOS e na maioria das distribuições Linux ele já vem instalado; no Windows, baixe o pacote de ferramentas em sqlite.org.
  • Python: o módulo sqlite3 faz parte da biblioteca padrão. Não é preciso instalar nada.
  • Interface gráfica: o DB Browser for SQLite permite abrir o arquivo e navegar pelas tabelas.

Para verificar a versão no terminal, rode o comando abaixo. Versões a partir de 3.35 suportam RETURNING e DROP COLUMN, que usamos neste curso.

sqlite3 --version

Comandos de ponto no terminal

Ao abrir o programa, você entra num prompt. Comandos que começam com ponto (.) não são SQL: são instruções do próprio sqlite3.

sqlite3 biblioteca.db        -- abre (ou cria) o arquivo
.tables                     -- lista as tabelas
.schema livro               -- mostra o CREATE TABLE da tabela
.headers on                 -- mostra os nomes das colunas
.mode column                -- alinha os resultados em colunas
SELECT * FROM livro;        -- comando SQL: termina com ponto e vírgula
.quit
Atenção: comandos SQL precisam de ponto e vírgula no fim; comandos de ponto não. Esquecer o ponto e vírgula faz o terminal esperar mais linhas, e o prompt muda para ...>.

O esquema do banco

O arquivo do banco guarda, além dos dados, o esquema: a descrição das tabelas, colunas, índices e restrições. O esquema fica numa tabela de sistema chamada sqlite_master. Consultá-la é a forma programática de fazer o que .tables e .schema fazem no terminal.

A instrução PRAGMA table_info(tabela) devolve as colunas de uma tabela, com tipo, se aceita nulo e se é chave primária. O exemplo do tópico usa exatamente isso.

Conectando a partir de Python

import sqlite3

con = sqlite3.connect("biblioteca.db")   # cria o arquivo se não existir
cur = con.execute("SELECT sqlite_version()")
print(cur.fetchone())
con.close()

Três conceitos do módulo sqlite3 aparecem em todos os tópicos seguintes:

  • Connection (con): representa o arquivo aberto. Fechar é responsabilidade do programa.
  • Cursor (con.execute(...) devolve um cursor): é onde estão os resultados de uma consulta. fetchone() pega uma linha, fetchall() pega todas.
  • Transação: alterações ficam pendentes até con.commit() (ou até o fim de um bloco with con:, que confirma se nada der errado).

Exemplo executável: criar o esquema e listar a estrutura

O script carrega o esquema da biblioteca de um arquivo .sql, lista as tabelas e mostra as colunas de livro lendo PRAGMA table_info. Ele usa um banco em memória, então não deixa arquivos no seu computador.

Ver o código completo 
import sqlite3

# Abrir (ou criar) um banco: em memória, para o exemplo não deixar arquivos.
con = sqlite3.connect(":memory:")
print("versão do SQLite:", sqlite3.sqlite_version)

con.executescript(open("biblioteca_schema.sql", encoding="utf-8").read())

# O catálogo do banco fica numa tabela de sistema: sqlite_master
print("\nTabelas criadas:")
for (nome,) in con.execute("SELECT name FROM sqlite_master WHERE type = 'table' ORDER BY name"):
    print(" -", nome)

# Estrutura de uma tabela (equivale ao comando .schema no terminal)
print("\nColunas de livro:")
for cid, nome, tipo, notnull, padrao, pk in con.execute("PRAGMA table_info(livro)"):
    print(f"  {nome:<8} {tipo:<8} NOT NULL={bool(notnull)!s:<5} PK={bool(pk)}")
con.close()

Erros comuns

  • Esquecer con.commit(): o INSERT parece funcionar na mesma conexão, mas some ao fechar o programa.
  • Usar caminho relativo sem saber a pasta de execução: sqlite3.connect("biblioteca.db") cria o arquivo onde você executa o programa, não onde o código está.
  • Abrir o arquivo em dois programas com escrita simultânea: o SQLite serializa as escritas, e a segunda pode receber “database is locked”.

Exercícios

1. Escreva um programa Python que crie o arquivo teste.db, crie uma tabela nota com id e texto, e liste as tabelas com sqlite_master.

Gabarito: con = sqlite3.connect("teste.db"); con.execute("CREATE TABLE IF NOT EXISTS nota (id INTEGER PRIMARY KEY, texto TEXT)"); con.commit(); SELECT name FROM sqlite_master WHERE type='table'. O IF NOT EXISTS permite rodar o programa várias vezes sem erro.

2. Qual a diferença entre .schema e SELECT * FROM livro?

Gabarito: .schema mostra a estrutura (a definição da tabela); o SELECT mostra os dados. Um é metadado, o outro é conteúdo.
