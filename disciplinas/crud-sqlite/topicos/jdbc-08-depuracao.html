Lendo uma mensagem de erro

Uma exceção tem três partes que convém ler nesta ordem: o tipo (SQLException), a mensagem (o que deu errado) e a pilha (onde aconteceu). A linha mais útil costuma ser a primeira que aponta para o seu próprio pacote, biblioteca, e não para a biblioteca do Java.

Animação: reconhecer três erros

A demonstração provoca três erros. Use os botões para ver a causa de cada um e o código que o produziu.

Passo a passo animado

O código abaixo é um trecho real do projeto. Avance com os botões ou use Animar: a linha em execução é destacada e a explicação acompanha.

public static void main(String[] args) throws Exception {
    System.out.println("== 1. URL errada");
    try {
        DriverManager.getConnection("jdbc:mysql://localhost/x");
    } catch (SQLException e) {
        System.out.println("SQLException: " + e.getMessage());
    }

    System.out.println("== 2. SQL com erro de digitação");
    try (Connection con = Conexao.abrir("demo07.db");
         Statement st = con.createStatement()) {
        st.execute("SELEC * FROM livro");
    } catch (SQLException e) {
        System.out.println("código " + e.getErrorCode() + ": " + e.getMessage());
    }

    System.out.println("== 3. chave estrangeira violada");
    try (Connection con = Conexao.abrir("demo07.db");
         Statement st = con.createStatement()) {
        st.execute("CREATE TABLE IF NOT EXISTS pai (id INTEGER PRIMARY KEY)");
        st.execute("CREATE TABLE IF NOT EXISTS filho (pai_id INTEGER REFERENCES pai(id))");
        st.execute("INSERT INTO filho (pai_id) VALUES (999)");
    } catch (SQLException e) {
        System.out.println("código " + e.getErrorCode() + ": " + e.getMessage());
    }
    new java.io.File("demo07.db").delete();
}

Breakpoints nas três IDEs

Quando a mensagem não basta, o depurador mostra o valor de cada variável no momento em que o programa para. Coloque um ponto de parada clicando na margem esquerda da linha, e inicie a depuração:

VS Codeclique na margem à esquerda do número da linhaRun and Debug ou F5, na classe com main
NetBeansclique na margem esquerda da linhaDebug → Debug File ou Debug Project

Com o programa parado, a janela de variáveis mostra os valores. Em trocarPrecos, por exemplo, você verá idA, idB, precoA e precoB. Avance linha a linha (Step Over) para acompanhar a ordem exata das instruções.

Exemplo executável: os erros provocados

A demonstração mostra três erros: uma URL que nenhum driver aceita, uma palavra digitada errado no SQL, e uma chave estrangeira violada.

package demos;

import biblioteca.Conexao;
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;
import java.sql.Statement;

/** Tópico 8: provoca os erros mais comuns para aprender a lê-los. */
public class Demo07Erros {

    public static void main(String[] args) throws Exception {
        System.out.println("== 1. URL errada");
        try {
            DriverManager.getConnection("jdbc:mysql://localhost/x");
        } catch (SQLException e) {
            System.out.println("SQLException: " + e.getMessage());
        }

        System.out.println("== 2. SQL com erro de digitação");
        try (Connection con = Conexao.abrir("demo07.db");
             Statement st = con.createStatement()) {
            st.execute("SELEC * FROM livro");
        } catch (SQLException e) {
            System.out.println("código " + e.getErrorCode() + ": " + e.getMessage());
        }

        System.out.println("== 3. chave estrangeira violada");
        try (Connection con = Conexao.abrir("demo07.db");
             Statement st = con.createStatement()) {
            st.execute("CREATE TABLE IF NOT EXISTS pai (id INTEGER PRIMARY KEY)");
            st.execute("CREATE TABLE IF NOT EXISTS filho (pai_id INTEGER REFERENCES pai(id))");
            st.execute("INSERT INTO filho (pai_id) VALUES (999)");
        } catch (SQLException e) {
            System.out.println("código " + e.getErrorCode() + ": " + e.getMessage());
        }
        new java.io.File("demo07.db").delete();
    }
}

Checklist de diagnóstico

  1. A mensagem indica o problema? Leia o tipo, a mensagem e a primeira linha do seu pacote.
  2. O driver e o slf4j estão no classpath? (aula 1)
  3. A chave estrangeira está ligada nesta conexão? (aula 2)
  4. O arquivo é o que você imagina? Confira a pasta de execução: caminhos relativos dependem dela.
  5. Outro programa está com o banco aberto? (código 5, “database is locked”)
  6. O valor que chegou ao banco é o esperado? Use o breakpoint para ver os parâmetros.

Exercícios

1. Provoque o erro 5 com duas conexões: uma com transação de escrita aberta, e outra tentando escrever.

Gabarito: na primeira conexão, setAutoCommit(false) seguido de um INSERT, sem commit. Na segunda, um INSERT recebe SQLITE_BUSY (código 5) depois do tempo limite.

2. Com um breakpoint em listarPagina, descubra LIMIT e OFFSET para a página 3 com tamanho 2.

Gabarito: LIMIT = 2 e OFFSET = (3 − 1) × 2 = 4. A terceira página começa na quinta linha.
