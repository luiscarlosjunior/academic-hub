O ResultSet é um cursor

Uma consulta não devolve uma lista pronta: devolve um ResultSet, um cursor posicionado antes da primeira linha. Cada next() avança uma linha e devolve false quando acabam. Os valores são lidos pelo nome da coluna (rs.getString("titulo")) ou pela posição, começando em 1.

Animação: o cursor percorrendo as linhas

A tabela mostra as linhas que a consulta devolve, e o destaque é a linha que o cursor está lendo. Avance e veja cada linha virar um objeto Livro na lista.

Passo a passo animado

O código abaixo é um trecho real do projeto. Avance com os botões ou use Animar: a linha em execução é destacada e a explicação acompanha.

public List<Livro> buscarPorTitulo(String trecho) throws SQLException {
    String sql = "SELECT id, titulo, ano, preco, isbn FROM livro WHERE titulo LIKE ? ORDER BY titulo";
    List<Livro> lista = new ArrayList<>();
    try (PreparedStatement ps = con.prepareStatement(sql)) {
        ps.setString(1, "%" + trecho + "%");   // o % é montado no código, não digitado pelo usuário no SQL
        try (ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                lista.add(mapear(rs));
            }
        }
    }
    return lista;
}

Paginação com LIMIT e OFFSET

Para mostrar uma página de cada vez, use LIMIT tamanho OFFSET (pagina - 1) * tamanho. Sempre inclua ORDER BY: sem ele, a ordem entre páginas pode mudar. No projeto, listarPagina calcula o deslocamento em Java e envia os dois números como parâmetros.

package demos;

import biblioteca.Conexao;
import biblioteca.Livro;
import biblioteca.LivroDao;
import java.sql.Connection;
import java.util.List;

/** Tópico 4: consultar (R do CRUD): por chave, por trecho de título e paginado. */
public class Demo04Consultar {

    public static void main(String[] args) throws Exception {
        String arq = "demo04.db";
        new java.io.File(arq).delete();
        try (Connection con = Conexao.abrir(arq)) {
            Conexao.criarTabelas(con);
            LivroDao dao = new LivroDao(con);
            dao.inserirLote(List.of(
                    new Livro(null, "Dom Casmurro", 1899, 29.9, "978-1"),
                    new Livro(null, "Memórias Póstumas", 1881, 39.9, "978-2"),
                    new Livro(null, "Vidas Secas", 1938, 24.5, "978-3"),
                    new Livro(null, "Capitães da Areia", 1937, 34.0, "978-4"),
                    new Livro(null, "A Hora da Estrela", 1977, 27.0, "978-5")));

            System.out.println("== por chave");
            dao.buscarPorId(3).ifPresentOrElse(
                    l -> System.out.println("achou: " + l),
                    () -> System.out.println("não existe"));
            System.out.println("id 99: " + dao.buscarPorId(99).isPresent());

            System.out.println("== por trecho do título ('da')");
            dao.buscarPorTitulo("da").forEach(System.out::println);

            System.out.println("== paginação, 2 por página");
            for (int pagina = 1; pagina <= 3; pagina++) {
                List<Livro> p = dao.listarPagina(pagina, 2);
                System.out.println("página " + pagina + ": " + p.stream().map(Livro::titulo).toList());
            }
        }
        new java.io.File(arq).delete();
    }
}

Erros comuns

  • Ler antes de next(): o cursor ainda não está em nenhuma linha.
  • Usar o ResultSet depois de fechar a conexão: extraia os dados dentro do try.
  • Montar o % no texto da consulta: coloque o trecho inteiro como parâmetro, como o projeto faz.

Exercícios

1. Escreva livrosAteAno(int ano) que devolve os livros publicados até o ano informado, em ordem de ano.

Gabarito: SELECT ... FROM livro WHERE ano <= ? ORDER BY ano, com ps.setInt(1, ano) e while (rs.next()) mapeando cada linha.

2. Por que mapear está separado dos outros métodos?

Gabarito: a conversão de linha para objeto é a mesma em todas as consultas. Um único lugar evita que uma coluna seja lida de formas diferentes.
