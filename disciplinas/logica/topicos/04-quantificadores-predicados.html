Tópico 4 · Quantificadores e predicados

A lógica proposicional não consegue dizer “todo cachorro é mamífero”: ela trata cada frase como uma unidade. A lógica de predicados (ou de primeira ordem) abre a proposição, separando objetos, propriedades e relações. Frege (1879) introduziu essa notação, e ela é a base de bancos de dados relacionais, da programação em Prolog e de verificação formal.

Predicados e universo de discurso

Um predicado P(x) é uma propriedade ou relação que vira proposição quando x recebe um valor. O conjunto de valores possíveis de x é o universo de discurso, e ele muda o valor de verdade de uma fórmula.

Seja P(x): “x + 3 = 2”. Nos números inteiros, ∃x P(x) é verdadeira (x = −1). Nos naturais, é falsa, porque nenhum natural satisfaz a equação. A mesma fórmula, dois universos, dois valores.

Quantificadores ∀ e ∃

  • ∀x P(x) (“para todo x”): verdadeira quando P vale para cada elemento do universo. Basta um contraexemplo para refutá-la.
  • ∃x P(x) (“existe x”): verdadeira quando há ao menos um elemento que satisfaz P.

Uma tradução padrão: “todo cachorro é mamífero” vira ∀x (C(x) → M(x)). A implicação, e não a conjunção, é a escolha certa para ∀. Já “existe um cachorro mamífero” vira ∃x (C(x) ∧ M(x)), com conjunção.

¬∀x P(x)  ≡  ∃x ¬P(x)
¬∃x P(x)  ≡  ∀x ¬P(x)

A negação “vira” o quantificador e nega o predicado. Use essas duas equivalências sempre que precisar provar algo por contraexemplo.

A ordem importa

Trocar a ordem de quantificadores de mesmo tipo não muda nada, mas trocar tipos muda tudo. Com universo dos naturais:

  • ∀x ∃y (y > x): para todo x existe um y maior. Verdadeira (y = x + 1).
  • ∃y ∀x (y > x): existe um y maior que todo x. Falsa, pois não há maior natural.

Exemplo: achando um contraexemplo

Afirmação: “para todo real x, x² ≥ x”. Para refutá-la, basta um x que quebre a desigualdade. Tentando x = 1/2: (1/2)² = 1/4 e 1/4 < 1/2. Logo ¬∀x (x² ≥ x) é verdade, e a afirmação original é falsa.

# Python: busca de contraexemplo em um conjunto finito
candidatos = [0, 0.5, 1, 2, 10]
contra = [x for x in candidatos if not (x * x >= x)]
print(contra)   # [0.5]

Um programa de teste encontra contraexemplos, mas não prova uma afirmação universal. Para provar ∀ sobre um domínio infinito, é preciso argumento lógico, como o do tópico 5.

No mercado de trabalho

Quantificadores são a linguagem de restrições em bancos de dados: “para todo pedido, existe um cliente” é uma chave estrangeira; “não existem dois pedidos com o mesmo número” é uma restrição de unicidade. Em verificação formal, a AWS usa raciocínio automatizado sobre políticas de acesso (IAM) para responder perguntas como “existe alguma requisição que esta política permita indevidamente?”, uma pergunta com ∃ ao lado de ∀.

Referência: Amazon Web Services, “Automated Reasoning” (documentação e publicações da equipe de raciocínio automatizado da AWS, 2020 em diante).
